# Architecture Rules

- Keep the project local-first unless the human explicitly approves a hosted dependency.
- Prefer existing project patterns over new abstractions.
- Do not introduce a framework unless it removes more complexity than it adds.
- Keep acceptance checks binary and repeatable.
- Do not mark a feature passing without evaluator evidence.
- Record durable decisions in `DECISIONS.md`.
- Record reusable lessons through memory candidates and the wiki.
