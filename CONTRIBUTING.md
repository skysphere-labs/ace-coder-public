# Working with this source release

Skysphere ACE CODER is published as a read-only source release. This repository
does not accept pull requests, patches, feature requests, or support tickets.
There is no commitment to review submissions or publish further releases.

You are welcome to fork the repository and develop, use, and distribute changes
under the [Apache-2.0 license](LICENSE) and the applicable third-party terms.
Run development, collaboration, issue tracking, and releases in your own fork.
A fork is independent and is not an official Skysphere Labs release.

## Building and changing a fork

Start with the [setup instructions](README.md#run-from-source),
[feature tour](docs/FEATURES.md), and [local coding guidance](AGENTS.md).
Keep changes focused and run the checks relevant to the behavior you change.
The configured desktop package targets are macOS and Windows.

Preserve applicable copyright, license, and attribution notices. Describe
modifications as required by the relevant licenses. Review
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) when redistributing source or
building packages, and follow the [branding guidance](TRADEMARKS.md).

Use your own provider accounts, GitHub configuration, signing credentials, and
release infrastructure. Do not include credentials, account data, transcripts,
personal screenshots, or local databases in a published fork.

## Security

Read [SECURITY.md](SECURITY.md) before sharing a vulnerability report. Fork
maintainers should publish their own security reporting and maintenance policy.
