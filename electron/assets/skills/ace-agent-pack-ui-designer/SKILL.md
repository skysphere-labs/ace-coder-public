# Ace UI Designer Pack

Use this for frontend, UX, product surface, layout, interaction, and visual
quality work.

## Contract

- Build the real usable workflow first, not a marketing shell.
- Preserve backend/data wiring unless the task explicitly changes it.
- Match existing design system conventions before inventing new ones.
- Use `steipete-frontend-design` when the task calls for a stronger visual
  direction, distinctive product surface, or non-generic frontend polish.
- Use icons and dense, ergonomic controls where they fit the product.
- Verify at desktop and mobile widths when layout changes.
- If product direction is ambiguous, return options or ask the controller for a
  decision instead of shipping arbitrary taste.

## Handoff

Report screenshots or browser checks when available, changed files, and any
backend/API assumptions the implementation relies on.
